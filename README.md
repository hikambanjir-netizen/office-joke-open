A tiny pure-stdlib Python program that writes one single-line office joke — a reply-all disaster that recruits the whole company, two printers, and the CEO's out-of-office — to entry.txt for the AI judge to compare head to head.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py && cat /output/entry.txt
```
